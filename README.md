## 🚀 Spotlight Project

### 🛡️ [Multi-Agent RAG Compliance Auditor](https://github.com/Krishna-Dhawangale/Multi-Agent-RAG-Compliance-Auditor)

> Upload a policy PDF and three AI agents return a compliance score, flagged violations, legal-risk assessment and fix recommendations.

```text
PDF upload → parse & chunk → embed → Qdrant
                                       │
   Agent 1: Compliance Checker  ──►  flags violations via RAG
   Agent 2: Legal Auditor       ──►  confirms findings & assesses risk
   Agent 3: Report Compiler     ──►  score + structured JSON report
                                       │
                            Streamlit dashboard
```
